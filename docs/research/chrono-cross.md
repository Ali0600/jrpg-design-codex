### M099 Home / Another World (mirrored dual dimensions)
pointers: [wiki:chrono.fandom.com/Another World] [wiki:chrono.fandom.com/Chrono Cross] [wiki:chrono.fandom.com/Astral Amulet] [gf:48347 §II. TH' BASICS, Shotgunnova]
row: M099
- Home World split from Another World when Kid saved Serge from drowning; each world keeps its own history, such as who leads Guldove and whether the Acacia Dragoons live [wiki:chrono.fandom.com/Another World] [wiki:chrono.fandom.com/Home World]
- The walkthrough's chapters run through the same places in both worlds, such as Arni Village and Lizard Rock in Home World and again in Another World [gf:48347 §00) Dream Sequence, Shotgunnova] [gf:48347 §04) Arni Village Another World D-04, Shotgunnova]
- The Astral Amulet crosses between the worlds at Opassa Beach [wiki:chrono.fandom.com/Astral Amulet] [gf:48347 §Anyway, approach the dawdling dwarves for, Shotgunnova]
- Crossing back and forth is how party members are recruited, items found and the story advanced; whether Poshul was invited in one world changes what happens in the other [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §04) Arni Village Another World D-04, Shotgunnova]

### M100 Element grid (spatial magic loadouts)
pointers: [wiki:chrono.fandom.com/Element] [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §II. TH' BASICS, Shotgunnova]
row: M100
- Each character has an Element Grid of up to eight levels, allocated from the menu [wiki:chrono.fandom.com/Element] [gf:48347 §II. TH' BASICS, Shotgunnova]
- An Element has a default level and a range; placed higher it is stronger, placed lower it is weaker, and some cannot move at all [wiki:chrono.fandom.com/Element] [gf:48347 §II. TH' BASICS, Shotgunnova]
- Elements are spells, consumables, traps, field modifiers, summons and each character's own techs [wiki:chrono.fandom.com/Element] [gf:48347 §II. TH' BASICS, Shotgunnova]
- Every character has an innate color, and same-colored Elements gain power [wiki:chrono.fandom.com/Element] [wiki:chrono.fandom.com/Innate] [gf:48347 §II. TH' BASICS, Shotgunnova]
- The grid grows with each level-up star [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §Don't forget about the New Game Plus, Shotgunnova]

### M101 Star levels (boss-driven growth, no grinding)
pointers: [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §Winged Shoes EVD% +18, Shotgunnova] [gf:48347 §00) Dream Sequence, Shotgunnova]
row: M101
- There is no experience system: a few small stat gains come from ordinary battles, then stats stay put until a boss is beaten for a star, which opens another few [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §Winged Shoes EVD% +18, Shotgunnova]
- Enemies are visible on field maps, so battles can be avoided by moving around them [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §00) Dream Sequence, Shotgunnova]
- Running away is a battle command [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §BATTLE MENU, Shotgunnova]

### M102 45 recruitable characters
pointers: [wiki:chrono.fandom.com/List of Chrono Cross characters] [wiki:chrono.fandom.com/Chrono Cross] [gf:27055 §III. Recruiting Characters, Daredevil3181 v4.1]
row: M102
- There are 45 playable characters [wiki:chrono.fandom.com/List of Chrono Cross characters] [wiki:chrono.fandom.com/Chrono Cross] [gf:27055 §VII. Character Relations, Daredevil3181 v4.1]
- Each has an innate color and unique techs [wiki:chrono.fandom.com/Chrono Cross] [gf:27055 §Level 7 Tech time, Daredevil3181 v4.1]
- Characters join through items found, dialogue answers, and choices; one three-way choice means only one of Pierre, Nikki and Guile joins on a first playthrough [gf:27055 §III. Recruiting Characters, Daredevil3181 v4.1] [gf:27055 §Tele-Porter and Swapping out Characters, Daredevil3181 v4.1] [gf:48347 §NIKKI TEAM START / GUILE TEAM START, Shotgunnova]
- Later playthroughs recover the rest: the recruiting guide plans separate saves for the other choices, and on New Game+ the Chrono Cross element brings back every character from the old file except Lynx [gf:27055 §Tele-Porter and Swapping out Characters, Daredevil3181 v4.1] [wiki:chrono.fandom.com/New Game+]

### M103 Field Effect (battlefield color economy)
pointers: [wiki:chrono.fandom.com/Element] [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §II. TH' BASICS, Shotgunnova]
row: M103
- The field shows the colors of the three most recently used Elements, each new one pushing the oldest out [wiki:chrono.fandom.com/Element] [gf:48347 §II. TH' BASICS, Shotgunnova]
- Those colors strengthen characters and Elements of the same color and weaken the opposite ones [wiki:chrono.fandom.com/Element] [gf:48347 §II. TH' BASICS, Shotgunnova]
- A field that is all one color allows that color's summons [wiki:chrono.fandom.com/Element] [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §II. TH' BASICS, Shotgunnova]

## Unverified or contradicted

- **Running from every fight.** M101 said running is always allowed. The wiki says players can run from all fights, bosses included; the walkthrough notes a Mt. Pyre boss that challenges again at once, so fleeing to heal does not work there. The row keeps only that running away is a command [wiki:chrono.fandom.com/Chrono Cross] [gf:48347 §12) Mt. Pyre Another World, Shotgunnova]
- **Ten years apart, and changes crossing between worlds.** The split in 1010 and events in one world changing the other (scorched ground growing plants) are on the wiki alone, so M099 names neither [wiki:chrono.fandom.com/Another World] [wiki:chrono.fandom.com/Chrono Cross]
- **Endings and accents.** M102 said every recruit adds to the endings and has a personal accent. Neither source says so, and both are cut; so is "New Game+ exists partly so you can recruit the ones you missed", which states an intent [gf:27055 §IV. Endings, New Game/Continue+, Daredevil3181 v4.1] [wiki:chrono.fandom.com/New Game+]
- **Enemies changing the field.** M103 said casts by anyone, enemies included, tint the field. Neither source says enemy casts count, so the row does not either [wiki:chrono.fandom.com/Element] [gf:48347 §II. TH' BASICS, Shotgunnova]
